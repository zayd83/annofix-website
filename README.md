# Annofix Installaties - website

Statische website (HTML/CSS/JS), mobile-first en responsive.

## Structuur
- index.html        Homepage (semantisch)
- css/style.css     Design-systeem + styling
- js/app.js         Mobiel menu
- assets/           Logo + (placeholder) afbeeldingen

## Lokaal bekijken
Open index.html, of gebruik de VS Code-extensie "Live Server".

## Design tokens (bovenin css/style.css)
- Navy #1B2A44 (primair) - Navy donker #12203A - Blauw #8CA5C5 (accent)
- Fonts: Sora (koppen) + Inter (tekst) via Google Fonts
